## How to view

| Viewer | Mermaid |
|--------|---------|
| **GitHub / GitLab** | Renders fenced `mermaid` blocks on preview |
| **VS Code / Cursor** | Markdown preview with Mermaid extension (often built-in) |
| **Plain text editor** | Read the numbers in captions; ASCII fallbacks included |

If a diagram does not render, use the **ASCII duplicate** under each chart.
