# Glossary

| Term | Meaning in Epact |
|------|------------------|
| **Synodic month** | Mean interval between identical lunar phases (~29.53059 d). |
| **Sidereal month** | Moon’s orbit relative to the stars (~27.32 d). |
| **Tropical year** | Mean equinox-to-equinox year (~365.24219 d). |
| **Lunar quarter** | One fourth of a synodic month (~7.38265 d). |
| **Spring–neap cycle** | Half a synodic month (~14.77 d) between spring tides. |
| **Epact** | Leftover days (or time) when a week, month, or year grid does not match a natural cycle-for example four 7-day weeks vs one synodic month. |
| **Intercalation** | Inserting leap days, weeks, or months to absorb epact. |
| **Incommensurable** | Two periods whose ratio is irrational (no exact integer ratio). |
| **Circadian lock** | Week boundaries stay on calendar dates, not drifting clock times. |
| **Beatty mix** | Pattern of two integer week lengths (e.g. 7 and 8) whose average targets a non-integer mean. |
| **Convergent** | Best rational approximation from a continued fraction expansion. |
| **Pareto front** | Set of designs where improving one goal worsens another; no single “winner.” |
| **Circaseptan** | About-seven-day biological rhythm; not proven as a universal human clock. |
| **Ultradian** | Rhythm shorter than a day (e.g. ~90 min sleep cycles). |
| **Infradian** | Rhythm longer than a day but shorter than a year. |
| **Metonic cycle** | ~19 tropical years ≈ 235 synodic months (lunisolar alignment). |
| **Metonic week grid** | 940 weeks (580×7 + 360×8 d) = 6940 d = 235 months (110×29 + 125×30 d); see [metonic-week-grid.md](03-search/metonic-week-grid.md). |
| **Tidal day** | Time between successive lunar transits (~24 h 50 min). |
| **Lock-in / diffusion** | A calendar package (e.g. named 7-day week + rest + law) spreads by contact and replaces local week lengths; coordination cost, not proof that one length is astronomically correct. See [why-seven.md](05-synthesis/why-seven.md). |
